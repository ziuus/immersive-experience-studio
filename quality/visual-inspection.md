# Visual Inspection

Load the actual running build. Inspect agreed viewports, first viewport and full progression; capture evidence; exercise hover/focus/active/loading/error/success states; test scroll, media, pointer/touch and keyboard; compare with blueprint; log reproducible defects; reinspect after fixes.

If browser automation is unavailable, do not claim visual QA. Use available evidence, label limitations and provide exact manual inspection steps.

Severity: P0 blocks core use/security; P1 major journey or visual failure; P2 noticeable defect with workaround; P3 polish.
