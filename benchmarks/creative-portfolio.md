# Benchmark: Creative Portfolio

Scenario: communicate a distinctive creative/technical identity and make selected work memorable and evaluable.

Evaluate specific thesis; compelling but credible opening; project context/role/process/evidence; exploration and quick evaluation; purposeful motion; mobile art direction; easy contact.

Failure signals: loud hero/weak case studies, generic 3D, unreadable type, inaccessible navigation, unsubstantiated skills or excessive load.
