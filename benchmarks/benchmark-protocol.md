# Benchmark Protocol

Test levels: (1) instruction compliance, (2) creative distinctness and grounding, (3) blueprint quality, (4) working prototype and real-output inspection, (5) production QA.

For each run record skill version, agent/model, prompt/context, tools, modules, time/cost if known, gate outputs, approvals, artifacts, inspection evidence, defects, critic report and outcome.

Maintain regression cases for generic concepts, visual defects, broken interactions and tool failures. Record symptom, root cause, corrective rule and regression test.

A persuasive plan is not a passing prototype; a prototype is not production delivery. Pass only against explicit criteria.
