# Immersive Experience Studio v3.0

A modular creative-production skill for signature-level digital experiences.

## Configuration
Approval at every major gate · Signature ambition · Hybrid specialist architecture · Universal scope.

## Installation
1. Copy this directory into the skill location supported by your agent.
2. Register/expose `SKILL.md` using that agent's skill-loading mechanism.
3. Preserve relative paths: the root skill references the modules.
4. Add the relevant agent adapter.
5. Verify the agent can discover and read the root skill. Copying files alone may not activate it; discovery conventions differ by agent.

## Validation
Start with instruction and creative tests from `benchmarks/benchmark-protocol.md`. Use the consumer-brand, Temis product-page and portfolio benchmarks. Do not build all three fully at once.

This package improves process discipline; it cannot guarantee perfect output. Results depend on model, tools, brief, assets, implementation and real inspection.
