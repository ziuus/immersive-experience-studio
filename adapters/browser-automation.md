# Browser Automation Adapter

Only use when browser automation is available and authorized.

Minimum matrix: wide desktop, laptop/tablet, narrow mobile; first viewport and full experience; keyboard; reduced motion. Start project using documented command; confirm URL/load; capture agreed viewports; exercise primary journeys and states; inspect console/network failures; measure performance if supported; record environment and defects; reinspect after fixes.

Do not claim real-device testing from desktop viewport emulation. Distinguish emulation from physical-device validation.
