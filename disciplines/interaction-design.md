# Interaction Design

For each control define user goal, affordance, input methods, states (idle/hover/focus/active/loading/success/error/disabled), feedback, exit/cancel, responsive behavior and privacy-compliant analytics if justified.

Exploration should reward curiosity while preserving agency. Provide entry, orientation, navigation and exit. Do not require precision pointer gestures for essential content.

Use semantic controls and landmarks, logical focus order, visible focus, keyboard operation, accessible names/statuses, contrast, text resizing, non-color meaning and touch targets. Never make hover the only access path. Test with keyboard, touch and assistive technology where available.
