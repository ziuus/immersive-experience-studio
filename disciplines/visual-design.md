# Visual Design

Check focal clarity, scale, hierarchy, rhythm, negative space, alignment, responsive composition, image crops and decorative purpose.

Define typography roles, scale, line length, line height, weight, tracking and responsive behavior. Verify font licensing and fallback. Preserve body readability.

Use semantic color roles and check contrast in actual contexts, including overlays and states. Specify assets by subject, framing, aspect ratio, lighting, treatment, format and rights. Clearly label conceptual placeholders; never present generated or placeholder product imagery as authentic photography.
