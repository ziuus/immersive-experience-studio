# Art Direction

Define thesis, visual world, emotional temperature, composition system, typography, color relationships, image/film/illustration treatment, materials, lighting, depth, graphic motifs, density/negative-space rhythm and responsive transformation.

A visual grammar is a set of repeatable decisions: when layouts are asymmetrical; how scale creates hierarchy; how imagery is framed; how type behaves across breakpoints; how transitions connect scenes; which colors carry meaning.

Specify key frames: first viewport, pivotal narrative moments, conversion/action frame and mobile equivalent. The concept must survive beyond the hero.

Avoid choosing a trend before understanding the brand, random effects, decorative complexity, and systems that collapse on mobile.
