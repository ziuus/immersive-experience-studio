# Accessibility Reference

- Use semantic HTML and correct heading order.
- Ensure all interactive controls are keyboard accessible and have visible focus.
- Provide accessible names and labels for controls and form fields.
- Maintain sufficient text and interface contrast.
- Do not communicate state through color alone.
- Provide meaningful alternative text for informative images; use empty alt for decorative images.
- Respect `prefers-reduced-motion` and avoid essential information conveyed only through animation.
- Avoid autoplaying audio; provide controls and user choice if sound is part of the concept.
- Ensure menus, dialogs, and forms have understandable focus and error behavior.
